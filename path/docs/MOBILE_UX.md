# Mobile UX v7

## Principi
- mobile-first: le azioni principali occupano tutta la larghezza disponibile;
- target touch minimo ~44px;
- input a 16px per evitare zoom automatico su iOS;
- bottom navigation per le 5 aree più usate;
- menu laterale per le aree secondarie;
- tab orizzontali scrollabili per suddividere pagine dense;
- modali come bottom sheet su smartphone;
- filtri in colonna su mobile;
- card e statistiche in griglia adattiva;
- tabelle mantenute leggibili con scroll orizzontale solo quando una tabella richiede realmente più colonne.

## Struttura a sottosezioni
### Presenze
- Riepilogo
- Assenze programmate
- Registro
- Dettaglio giocatore

### Multe
- Riepilogo
- Tipologie
- Storico

### Carichi
- Andamento
- Carico per giorno
- Confronto giocatori

Le sezioni vengono aperte senza sovraccaricare la schermata iniziale.
